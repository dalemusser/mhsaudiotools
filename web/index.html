MHS Audio Generator

Generate spoken dialog audio for the game with ElevenLabs.

Point it at your dialog — a Dialogue System export or a writer's script — pick the voices, and it produces one audio file per line in the exact folder layout the game expects. Two versions are available: the app (a normal desktop program — what most people want) and the CLI (a command-line tool for automation).

Installing the app

These builds aren't signed with a paid developer certificate yet, so macOS and Windows show a one-time "unidentified developer" warning. The steps below get past it safely.

🍎 macOS

  1. Unzip the download and drag MHS Audio Generator.app into your Applications folder.
  2. The first time, right-click the app → Open, then click Open in the dialog. (Double-clicking is blocked the first time because the app isn't signed — right-click → Open gets past it, just once.)

🪟 Windows

  1. Double-click the .exe. If SmartScreen says "Windows protected your PC," click More info → Run anyway.
  2. The app needs Microsoft's WebView2 runtime, already present on nearly all Windows 10/11 machines. If the window is blank, install it free from Microsoft and reopen.

🐧 Linux

  1. Extract: tar -xzf mhsaudio-app-linux-*.tar.gz
  2. Make it runnable: chmod +x mhsaudio
  3. Install the runtime libraries: 
    sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0
  4. Run it: ./mhsaudio

ElevenLabs API key

Both tools need an ElevenLabs API key. Sign in at elevenlabs.io, create a key under your profile's API Keys, and paste it into the app when prompted on first run (it's saved to ~/.elevenlabs_key, readable only by you). For the CLI, set ELEVENLABS_API_KEY or save the key to ~/.elevenlabs_key. Never share the key — anyone with it can spend the account's credits.
